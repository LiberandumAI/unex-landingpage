# UNEX coin — бриф v2 (золото, BTC / ETH, больше деталей)

Изменения относительно v1 (`unex-coin-delivery`). Всё, что не упомянуто, остаётся как в v1:
размеры, LOD, UV, экспорт в GLB, запечённые карты, имена объектов и материала.

## 1. Материал — золото, не бронза

- BaseColor: тёплое золото около #E8B85A в поле монеты, чуть светлее #F2CB76 на ободке
  и кромке (полированные), чуть темнее #B8873A в углублениях гравировки.
  Вариация тона ±6%, без «жёлтого пластика»: не чистый #FFD700.
- Roughness: поле 0.30, гравировка 0.38, ободок и кромка 0.18. Микроцарапины ±0.06.
  Минимум 0.15. Это заметно глаже v1 — золото должно давать длинный блик.
- Metallic 1.0 везде. Без emission, без clearcoat.

## 2. Лицо — Bitcoin, оборот — Ethereum

- Лицевая сторона (+Z): глиф ₿ как в v1, высота 55% диаметра, рельеф 0.006.
- Оборотная сторона (−Z): логотип Ethereum — октаэдр «Ξ» в классической разбивке
  на 6 граней. Высота 52% диаметра, рельеф 0.006. Грани октаэдра с разной глубиной:
  верхние две 0.006, нижние две 0.004, чтобы читались как объём при вращении.
  Никаких фирменных цветов, только рельеф металла.
- Круговая надпись «UNEX ACADEMY · TASHKENT · MMXXVI» переносится на лицевую сторону,
  вдоль ободка, вокруг ₿. Между всеми тремя частями обязательны разделители «·»
  через равные интервалы (в v1 «MMXXVI» слипалось с «UNEX»).
  Кегль надписи увеличить в 1.4 раза относительно v1.

## 3. Больше деталей

- Рифление кромки (reeding) — теперь реальной геометрией на Desktop-меше:
  180 рёбер, глубина 0.003. На LOD1 по-прежнему только normal map.
- Внутренняя декоративная окружность на обеих сторонах: тонкая канавка на 0.86 диаметра,
  ширина 0.004, глубина 0.002.
- Микротекст по внутренней кромке ободка на лицевой стороне: «BLOCKCHAIN · DIGITAL
  ASSETS · WEB3 · SECURITY FIRST», кегль такой, чтобы читался только крупным планом.
- Поле монеты — лёгкая «чеканная» неровность в normal map (frosted field), чтобы
  блик ломался, а не скользил как по стеклу.
- Ободок — зеркальный (roughness 0.18), поле — сатин (0.30): контраст поверхностей
  и есть «дорогая» монета.

Бюджет: Desktop до 60 000 tris (рифление и два логотипа), LOD1 до 10 000.

## 4. Рендеры для утверждения

Те же четыре ракурса, что в v1, плюс пятый: оборот с Ethereum, 3/4 сверху.
Фон #100904, один тёплый key справа сверху, холодный rim слева сзади — ровно как
свет в сцене сайта, чтобы заказчик утверждал то, что увидит на лендинге.

## 5. Проверка

- Khronos validator 0/0, `gltf-transform inspect`: 2 меша, 1 материал, 3 текстуры.
- Оборот проверить в просмотрщике: Ξ не зеркальный, надпись читается по часовой.
